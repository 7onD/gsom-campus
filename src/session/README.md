# «Сессия»

Пункт «Настройки → Сессия → Экзамены и зачёты»: экзамены, зачёты, пересдачи и комиссии своей группы. Вспомогательный инструмент, не официальный источник. Сделана отдельным модулем, чтобы её можно было быстро убрать.

## Включение

- На сайте: `VITE_SESSION: "1"` в `.github/workflows/pages.yml`.
- Локально: `npm run stand` (выключатель уже стоит) или `VITE_SESSION=1 npm run dev`.

Без `VITE_SESSION=1` модуль не попадает в сборку.

## Пересдачи и комиссии

В расписании нынешней группы прошлогодних долгов нет: они в расписании той же группы под прошлогодним номером. Сопоставление лежит в `previous-groups.json` и действует один учебный год. **После смены номеров групп (сентябрь) обновить:** `npm run refresh-groups`, затем `node src/session/build-previous.mjs`. Пока не обновлено, приложение прошлогодние пересдачи не показывает и пишет об этом.

## Тесты

Входят в `npm test` (`src/session/model.test.ts`).

## Удалить целиком

`zsh src/session/remove.sh` из корня проекта, затем `npm test && npm run build`, коммит и пуш. Только выключить на сайте — убрать строку с `VITE_SESSION` в `pages.yml`. Выбор элективов и преподавателя общий с расписанием и остаётся. Кэш `vsm:session:*` в браузере безвреден.
