# «Сессия»

Пункт «Настройки → Сессия → Экзамены и зачёты»: экзамены, зачёты, пересдачи и комиссии своей группы. Вспомогательный инструмент, не официальный источник. Сделана отдельным модулем, чтобы её можно было быстро убрать.

## Включение

- На сайте: `VITE_SESSION: "1"` в `.github/workflows/pages.yml`.
- Локально: `npm run stand` (выключатель уже стоит) или `VITE_SESSION=1 npm run dev`.

Без `VITE_SESSION=1` модуль не попадает в сборку.

## Пересдачи и комиссии

В расписании нынешней группы прошлогодних долгов нет: они в расписании той же группы под прошлогодним номером. Сопоставление лежит в `previous-groups.json` и действует один учебный год. Сопоставление обновляет ежедневная задача (`.github/workflows/refresh-groups.yml`). Если сайт ещё не опубликовал раздел прошлого года или сопоставилось меньше 80% групп, прежний файл остаётся, а о проблеме приходит сообщение (в сентябре это ожидаемо, пока раздела нет). Пока список относится к другому учебному году, приложение прошлогодние пересдачи не показывает и пишет об этом. Вручную: `npm run refresh-groups`, затем `node src/session/build-previous.mjs`.

## Смена семестра

Пока в новом семестре нет ни одного экзамена или зачёта, а также первые 60 дней семестра, вместе с ним загружается прошлый: январские экзамены не пропадают 1 февраля.

## Сбои

Неудачная загрузка отправляет событие `session_error` с этапом (текущий семестр, прошлый семестр, прошлогодние пересдачи). Без сети событие не отправляется.

## Тесты

Входят в `npm test` (`src/session/model.test.ts`).

## Удалить целиком

`zsh src/session/remove.sh` из корня проекта, затем `npm test && npm run build`, коммит и пуш. Только выключить на сайте — убрать строку с `VITE_SESSION` в `pages.yml`. Выбор элективов и преподавателя общий с расписанием и остаётся. Кэш `vsm:session:*` в браузере безвреден.
