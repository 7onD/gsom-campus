# ВШМ.Кампус

Мобильный веб-навигатор по главному корпусу ВШМ СПбГУ (Санкт-Петербургское шоссе, 109, лит. А): расписание группы и маршрут до аудитории на стилизованной карте. Учебный проект по управлению проектами.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173, доступен и по сети — для проверки с телефона
npm run build    # проверка типов + сборка в dist/
npm test         # маршруты, клиент расписания, хранилище настроек (22 теста)
npm run check-routes   # все аудитории достижимы от входа; примеры маршрутов
```

Адрес с `?now=2026-11-02T09:00` подменяет «текущее время» (например, чтобы проверить «Идёт сейчас» или воскресенье → понедельник). Вкладка в адресе: `#schedule`, `#map`, `#settings`.

## Экраны

Нижняя плавающая панель вкладок в стиле «жидкое стекло» (скользящая стеклянная линза, перетаскивается пальцем).

- **Расписание** — день недели, лента Пн–Вс (окно 4 недели), карточки пар с цветной полоской по типу занятия. Идущая пара выделена рамкой со свечением, бейджем «Идёт сейчас» и полосой прогресса. Тап по паре или кнопка «На карте» открывает карту с маршрутом до аудитории. Пары онлайн, в другом корпусе или без аудитории на плане маршрута не имеют.
- **Карта** — векторный план двух этажей: приближение и перемещение жестами, поиск аудитории, выбор тапом по помещению, чип «Ближайшая пара», выбор точки старта (главный вход, центральный холл, гардероб, конференц-зал, деканат), переключатель этажей, карточка маршрута с шагами. После построения маршрута карта сама приближается так, чтобы весь участок был виден крупно; при многоэтажном маршруте участки переключаются кнопками «1 этаж / 2 этаж».
- **Настройки** — выбор группы чипами (курс → программа → группа), факультативы и элективы (все выключены, включаются нужные), «Связаться с разработчиками» (заглушка), «Как пользоваться», «О приложении».

## Решения (подтверждены пользователем)

- Все аудитории обоих этажей, переход между этажами только по лестницам; планы со стенда (`assets/plans/floor1.jpg`, `floor2.jpg`) — единственный источник истины.
- Центральный холл пересекается только по центру; от гардероба выход влево или вправо (проход между стойкой и хранением), срез за гардеробом не размечен; старт «Конференц-зал» — у нижней точки круга; «Деканат» = Офис программ бакалавриата (2 этаж, 2230/2231).
- Светлый интерфейс в стиле «Свежая» с карточками пар и активной парой по образцу тёмного макета; прототипы стилей лежат в `docs/design/`.
- Настройки хранятся на устройстве (localStorage, при его недоступности cookie), аккаунта нет.

## Карта: как устроена

Растровый план не показывается. Из него получены векторные данные, поэтому карта чёткая при любом приближении, а подписи постоянного экранного размера.

1. `tools/ocr.swift` (macOS Vision) — распознаёт номера и подписи → `data/ocr-floorN.json`.
2. `tools/build_floor1.py`, `build_floor2.py` — якоря (аудитории, точки интереса, лестницы) и осевые линии коридоров для маршрутизации → `src/data/floorN.json`.
3. `tools/vectorize.swift` — выделяет контур здания и каждое помещение по цветам плана и привязывает номера → `data/vec-floorN.json`. Скомпилировать: `swiftc -O tools/vectorize.swift -o vectorize`; запуск: `vectorize assets/plans/floor1.jpg src/data/floor1.json data/vec-floor1.json`.
4. `tools/build_map.py` — добавляет подписи, иконки, компас → `src/data/map1.json`, `map2.json`.

Все координаты — в пикселях исходных планов, поэтому раскладка совпадает с оригиналом. Для проверки разметки: `tools/grid.swift` (план с сеткой), `tools/overlay.py` (коридоры и привязки поверх плана).

## Расписание

Источник — `https://timetable.spbu.ru/api/v1`: отдаёт JSON, разрешает запросы из браузера (CORS). Окно данных — 4 недели одним запросом `/groups/{id}/events/{от}/{до}` (формат с `?from=&to=` отдаёт только неделю). Сервер отвечает медленно (10–30 с): таймаут 30 с, один повтор, кэш в `localStorage`. Список групп бакалавриата (наборы 2023–2026) — статический снимок `src/data/groups.json` (`npm run refresh-groups`).

Пары «по выбору» различаются по префиксу названия: `Факультатив. …` и `Электив. …` (поле `IsElective` в API всегда `false`). Курс = название без префикса и без типа занятия.

## Структура

- `src/main.ts` — сборка: данные здания, граф маршрутов, три экрана, панель вкладок.
- `src/store.ts` — общее состояние (вкладка, группа, расписание, факультативы, запросы маршрута).
- `src/tabbar.ts`, `src/views/{schedule-view,map-screen,settings-view}.ts` — интерфейс; рядом `.css`.
- `src/mapview.ts` — векторная карта (жесты, подписи, маршрут, подсветка, `fitBounds`).
- `src/routing.ts` — граф коридоров, кратчайший маршрут (Дейкстра), лестницы между этажами.
- `src/timetable.ts`, `src/prefs.ts` — клиент расписания, хранение настроек.
- `src/styles/tokens.css` — дизайн-токены (цвета, радиусы, тени, «стекло»).
- `src/data/` — данные этажей, карты, лестниц, групп. `tools/` — скрипты подготовки данных. `docs/design/` — макеты стилей.

## Ограничения

- Двери части аудиторий (1206, 1214, 1215, 1222, 1236, 1237, 2101–2106, 2134–2139) и положение 009, 010, 014 определены приблизительно; на 2 этаже нет проходов по кольцу вокруг пустот над вестибюлем.
- Дубли номеров на плане (1124, 1129–1134, 2203, 2236–2247) различаются подписью «слева/справа на плане» или «северная часть / вестибюль / крыло»; расписание передаёт только номер, поэтому маршрут строится к первому варианту.
- Расписание не различает подгруппы внутри курса.
- Форма обратной связи — заглушка.
